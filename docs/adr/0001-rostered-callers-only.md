# Only rostered foremen can use the assistant

The assistant refuses any caller whose number is not on the roster (one line pointing to the office's main number, then hang up). We chose this over taking requests from unknown numbers flagged "unverified" because it removes the risk of disclosing job details to the wrong person and avoids identity verification in the call flow. Cost: a foreman calling from a borrowed phone is turned away; mitigated by registering multiple numbers per foreman.
